Darren's 50th RSVP site — first draft

Files:
- index.html
- styles.css

To make it live:
1. Create a Google Form with fields such as:
   - Name
   - Will you be joining us? (Yes / No)
   - Number attending
   - Dietary requirements
   - Optional message
2. In Google Forms, click Send > Link and copy the form URL.
3. Open index.html and replace:
   YOUR_GOOGLE_FORM_LINK
   with your actual Google Form URL.
4. Replace [Add venue here] with the venue.
5. If 7.00pm is not correct, edit that line too.
6. Upload index.html and styles.css to Cloudflare Pages or GitHub Pages.

Recommended approach:
Keep the invitation page bespoke and let Google Forms handle the responses.
That gives a polished front end and a reliable free RSVP system.
